## Run the notebook

Use Python 3.12 and create an isolated environment. From this folder:

```sh
python -m venv .venv
# macOS/Linux
source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
```

Install the **system Graphviz application**, not just the Python package. Use your platform's package manager (for example, `brew install graphviz` on macOS or `sudo apt install graphviz` on Ubuntu). On Windows install Graphviz and add its `bin` directory to PATH. Confirm `dot -V` succeeds.

Open Jupyter and use Restart Kernel and Run All, with this folder as the working directory:

```sh
jupyter notebook Mushroom_Tree_Models.ipynb
```

For unattended execution:

```sh
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 Mushroom_Tree_Models.ipynb
```

The declared grids require 3,780 cross-validation fits and can take tens of minutes or longer depending on the machine. Grid searches use four workers; each ensemble uses one internal worker. Reduce search workers to one if memory is limited. An institutional certificate error should be resolved by configuring your trusted CA certificates, not disabling HTTPS validation.

All paths are relative to this folder. The notebook creates `figs/` and `results/`. To detect obsolete outputs after changing the analysis, delete these two generated folders before a fresh run.

## Reproducibility and provenance

Seed 4372 controls the split, row CV, group CV and model randomness. Preprocessing and supervised selection are fitted separately within each validation fold. The delivered selected settings were independently refitted and checked against saved predictions. Package versions, source fingerprint and train/test row IDs are exported. Floating-point values can vary across hardware or library versions; timing columns and PDF metadata are not deterministic scientific results.

The same test set was evaluated in earlier project versions and is retained for comparison. Final feature policies and hyperparameters are selected using training cross-validation. Training-only grouped diagnostics hold fixed five-trait groups apart. Feature selection is refitted in each fold, so 981 validation rows per model have familiar inputs under the selected traits. They reuse row-CV-selected settings and a development-selected grouping representation; they are conditional stress tests, not nested validation of the whole model-selection procedure. Groups are not species.
